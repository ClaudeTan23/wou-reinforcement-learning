# Used Car Price Prediction & Deep Reinforcement Learning on Acrobot

## Project Overview

This project demonstrates the application of **Deep Learning** and **Reinforcement Learning** for two key tasks:

1. **Used Car Price Prediction**  
   A Deep Neural Network (DNN) model predicts the resale price of used cars based on features like brand, year, mileage, fuel type, and transmission type.

2. **Deep Reinforcement Learning on Acrobot**  
   A Deep Q-Network (DQN) agent is trained to solve the Acrobot environment using trial-and-error, learning to swing a two-link pendulum to an upright position.

---

## Milestones

### Milestone 1: Acrobot Environment Setup  
- Installed TensorFlow, Keras, Gym, and Keras-RL2.  
- Initialized Acrobot environment and explored state and action spaces.  
- Ran random episodes to observe environment behavior.  
- Designed and implemented the Q-Network architecture.  

### Milestone 2: DQN Agent Creation, Training, and Evaluation  
- Built and compiled the DQN agent using Keras-RL2.  
- Trained the agent on the Acrobot environment.  
- Evaluated agent performance and visualized actions.  
- Saved and reloaded model weights for testing.  

### Milestone 3: Data Preparation for Car Price Prediction  
- Performed data cleaning and preprocessing.  
- Encoded categorical variables using one-hot encoding.  
- Visualized data distributions and correlations.  

### Milestone 4: DNN Model for Car Price Prediction  
- Split data into training and testing sets.  
- Applied feature scaling techniques.  
- Built, compiled, and trained a Deep Neural Network (DNN).  
- Evaluated model performance using MSE, MAE, RMSE, and R² metrics.
